Settings

What this session has printed: the command each game was launched with, where each install went, anything that went wrong, and the running game's own output under its title — whether or not there is a terminal to show it.
The Python server's address on your network, e.g. http://192.168.1.20:8420
Where downloaded games are stored on this machine. Add a second directory — on another drive — and the library spreads across both: a game already on a drive stays there, and a new one goes wherever there is the most room. The first directory is also where Wine prefixes live, so PC saves stay put when the rest of the list changes.
Cloud saves
Keeps save data on the library server so a playthrough follows you between machines. A save is uploaded when you quit a game and offered back when this machine is behind. The server keeps the last few versions, and restoring moves the local save aside rather than deleting it.
Only needed if the server has SAVE_TOKEN set. The saves are the one writable thing it exposes; everything else it serves is read-only.
Descriptions, cover art, screenshots and trailers come from RAWG; a free key takes a minute to get. The key is sent to the library server with each request, so the server needs none of its own. Nothing already in a game's folder is overwritten.
The emulator's own data directory — saves live under nand/user/save inside it. Found automatically where possible. Each game is identified from its own installed files, or learned the first time you play it, so there is nothing to look up.
Each PC game runs in its own prefix — Wine's or Proton's, the layout is the same — which isolates games from each other and makes that prefix the game's save data. Leave this empty to keep them in .wine-prefixes beside the install directory. Games played before this existed kept their saves in the shared ~/.wine; copy those across by hand if you need them.
Command and arguments used to launch each platform. For a native install, Command is just the binary name or path. For a Flatpak — likely for PCSX2 and Eden — set Command to flatpak and Args to run <app-id> --, e.g. run net.pcsx2.PCSX2 --. PC additionally picks a runtime: Wine, or Proton for the DirectX 11 and 12 titles Wine alone struggles with. "Check" tests the values currently typed here, not what's saved yet.
Library server (nsz) Not checked
Checks whether the server itself has nsz available for Switch conversions, and how much room is left on its library drives.
Controller & keyboard sounds
Plays a short sound when navigating or selecting with a gamepad or keyboard. Mouse clicks stay silent.
