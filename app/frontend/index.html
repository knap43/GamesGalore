Where downloaded games are stored on this machine.
Cloud saves
Keeps save data on the library server so a playthrough follows you between machines. A save is uploaded when you quit a game and offered back when this machine is behind. The server keeps the last few versions, and restoring moves the local save aside rather than deleting it.
Only needed if the server has SAVE_TOKEN set. The saves are the one writable thing it exposes; everything else it serves is read-only.
The emulator's own data directory — saves live under nand/user/save inside it. Found automatically where possible. Each game is identified from its own installed files, or learned the first time you play it, so there is nothing to look up.
Each PC game runs in its own Wine prefix, which isolates games from each other and makes that prefix the game's save data. Leave this empty to keep them in .wine-prefixes beside the install directory. Games played before this existed kept their saves in the shared ~/.wine; copy those across by hand if you need them.
Command and arguments used to launch each platform. For a native install, Command is just the binary name or path. For a Flatpak — likely for PCSX2 and Eden — set Command to flatpak and Args to run <app-id> --, e.g. run net.pcsx2.PCSX2 --. "Check" tests the values currently typed here, not what's saved yet.
